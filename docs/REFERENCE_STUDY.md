최신 재검토와 Lintel 비교·반영 내용은 [REFERENCE_UPDATE.md](REFERENCE_UPDATE.md)를 참고하세요. 아래 적용표는 v3.4/v3.5 당시 기록입니다.
껍데기 페이지(`index.html`)는 상단 CAD 바(01~07 번호, 변형 알약 버튼, OPEN ↗, 바 접기)와 각 데모를 띄우는 iframe 하나로 되어 있습니다.

## 공통 문법 — 7개 데모가 모두 쓰는 것

## 데모별

### 01 Exploded House (PURLIN // AXO-01)
- **A · The Board**: 6개 층위(바닥 · 구조 · 유리 · 외장 · 지붕구조 · 지붕)가 시공 순서대로 내려앉습니다.
  - 오른쪽 지시선 목록(번호 + 재료 사양)에서 현재 층위가 주황으로 강조됩니다.
  - 그다음 렌즈가 눈높이 원근으로 넓어지며 실내로 들어갑니다(DINING → LIVING → LOFT → RIDGE).
  - 그림체는 굵은 외곽선, 판재 해칭, 연한 단색 — 일러스트형 축측도입니다.
- **B · Unfolded Room**: 방의 6면(바닥 · 4벽 · 천장)을 펼친 전개도에 재료 태그(SG-01 SAGE LACQUER …)와 치수가 붙어 있습니다. 스크롤하면 상자로 접히고, 문을 지나 주방으로 들어갑니다.
- **C · Floor by Floor**: 5층 CLT 사무동이 한 층씩 쌓입니다(GROUND · L1~L4 · ROOF · CORE 목록). 카메라가 3층에 서 있는 동안 4층이 위에서 내려와 천장이 됩니다.
- 사용자 판단: 분해도는 "예쁘지 않다"는 의견에 따라 우리 앱에서 삭제했습니다(v3.4).

### 02 Section Sweep (COTA // SWP-02)
- 2D 단면도에서 시작합니다: 포셰, 축선 A~D, 레벨 ±0.00~+8.00, 태양 고도선(21 MAR 51° · 21 JUN 72° · 21 DEC 27°, 주황 점선), 표제란.
- 렌즈가 열리면 **"CAD CUT PLANE X = …" 주황 평면이 좌→우로 훑습니다.** 평면 뒤는 선화, 앞은 재질·하늘로 바뀝니다.
- 거실(이중 높이) → 위층 라운지 → 침실 등 실사 투어를 하고, "BACK THROUGH THE CUT"으로 다시 단면에 돌아옵니다.

### 03 Open Section (POCHÉ // SEC-03)
- 선이 그려지는 단면에서 시작합니다. **"THE LENS OPENS. THE CUT KEEPS ITS SIZE."** — 단면 크기를 고정한 돌리 줌입니다.
- 절단면 쪽에서 층마다 방문합니다(STAIR → KITCHEN → PATIO → LIVING → POOL).
- 흙 단면은 사선 해칭, 벽 단면은 검은 포셰이고, 계단·방마다 축척 인물이 있습니다.
- 끝은 "THE SAME SECTION, RENDERED IN MATERIAL AND LIGHT." 그 아래로 회사 소개, 작업 목록, 연락처 섹션이 이어집니다.
- C 변형은 계단을 따라 내려가는 동선입니다.

### 04 Build Time-Lapse (SEQUENCE // A-901)
- 첫 화면은 공정 단계별 축측도 6장 스토리보드(EXCAVATE … FIT OUT, WK 01–38)입니다.
- 첫 장으로 다이빙하면 실사 현장이 됩니다.
  - **굴착기, 철근, 옹벽, 동바리(PROPS) 받친 슬래브 거푸집, 타워크레인**
  - 하단에 소형 간트, "WEEK 14 // WALLS, MEZZANINE · 28 PROPS" 같은 주차 표기
- 마지막에 6번 도면으로 다시 빠져나옵니다(도면 → 현장 → 도면 순환).

### 05 Schedule Build (PURLIN // CPM-05)
- **스크롤·▶ BUILD 재생 버튼·주차 스크러버(0~14주)** 로 움직입니다. 원본 `view.js`의 wheel 핸들러는 공정 주차와 실내 투어를 모두 구동합니다.
- 텔레메트리 카드: "WK 08 / 14 · MON 19 APR 2027 · TR-06 // 50% COMPLETE · CAM SIG", 공종명, 사양
- 공정표: WBS // CRITICAL PATH, 일수(4d · 6d · 10d …), TODAY 표시
- 현장 요소: 터파기 구덩이, **흙더미, 굴착기, 자재 팔레트, 펜스**
- **B · 1:1 Sheet**: 기초 평면도가 1:1로 땅 위에 그려진 상태(축선 번호, 치수선)에서 건물이 올라갑니다.
- **C · Site Camera**: 현장 CCTV 화면(CAM 02 · 날짜 · 큰 시계 12:18)
- 준공 후에는 방 정지점 버튼(ENTRY · LIVING · KITCHEN · LOFT · OVERLOOK)이 있습니다.

### 06 Card Model (ATELIER 1:100 // MDL-06)
- 로더: 칼(스칼펠)이 선을 긋는 진행률 "SCORING THE FIRST SHEET 000→100"
- 밤 책상 위의 흰 카드 모형입니다. 커팅 매트, 벽에 핀으로 꽂은 도면, 스탠드 조명이 있습니다.
- **이중 축척 표기**: "24.6 CM ON THE DESK // 1:100 · 24.6 M IN THE HOUSE // 1:1"
- 축척 인물 높이까지 내려가면 카드가 실제 집이 되고 스탠드가 태양이 됩니다. 마지막에 "AND BACK TO THE DESK."

### 07 Sunlit Elevation (ALBION ROW // ELV-07)
- **A · One Door**: 정면도의 해칭이 곧 실제 그림자입니다(45° 해칭 = 그림자 영역).
  - 스윕이 지나가면 벽돌이 되고, 해가 움직이고, 문이 열려 들어갑니다(STREET · PORCH · PARLOUR · ATRIUM · GARDEN).
  - 정지점 사양 3칸(ATRIUM 6.40 M HIGH · ISLAND HONED STONE · GLAZING CRITTALL STEEL)이 붙습니다.
- **B · The Row**: 6세대 연립의 입면에 **분양 상태(SOLD · RESERVED · AVAILABLE)** 를 표시하고, 선택 세대를 주황 윤곽으로 강조합니다. CTA는 "RESERVE PLOT 04"입니다.
- **C · The Face**: 1:20 벽돌 상세. 정면광에서는 평평하다가 빛이 비스듬해지면 무늬(다이아퍼)가 드러납니다.

## 우리 앱에 적용하는 것 (v3.5)

1. **그림자 = 45° 해칭** (07): 도면 장면에서 직사광이 닿지 않는 면을 화면 공간 사선 해칭으로 칠합니다(셰이더). 입면 장면의 태양은 45° 근처로 둡니다.
2. **스캔 평면 스윕** (02·07): 돌리 줌 구간에서 주황 "CAD SCAN X = …" 평면이 건물을 훑으며 선화 → 재질로 바꿉니다(셰이더 월드 x 비교).
3. **단면 장면** (02·03): 준공 뒤 수직 절단면이 앞에서 들어와 건물을 자릅니다.
   - 단면 크기를 고정한 돌리 줌을 쓰고, 층마다 방문한 뒤 평면도로 넘어갑니다.
   - 흙 단면은 해칭, 벽 단면은 포셰로 그리고, 레벨 표기를 붙입니다.
   - 기준층 실내를 위층에 복제해 단면이 비어 보이지 않게 합니다.
4. **현장 장비** (04·05): 굴착기, 덤프트럭, 흙더미, 기초 철근, 슬래브 동바리, 외부 비계와 안전망, 자재 팔레트, 작업자. 모두 공정에 묶어 나타나고 사라집니다.
5. **축척 인물** (03·06·07): 현관 앞·가로·실내
6. **서사 캡션** (07·03): 장면 박자마다 왼쪽 아래 큰 문장
7. **정지점 이름 탭** (01·05·07): 미니 평면 아래 클릭 탭
8. **하단 상태줄** (01·07): PROJ(정사·투시와 화각) · SEQ % · SUN 고도·방위 · 장면 코드
9. **로딩 진행률** (01·06): "PLOTTING A-201 · 63%"

보류: 분해도(사용자 요청으로 삭제), 1:1 기초 평면 시트(05B), CCTV 모드(05C), 카드 모형(06), 분양 상태 오버레이(07B — 다세대·기숙사에 적용 후보).
