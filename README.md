**공사비·공기 산정 패널**(우측 상단 버튼): 마감 등급, 평당 단가, 간접비, 골조 층당 작업일, 주당 작업일, **지연 시나리오(공정 + N주)**, 토지비·자기자본·한도·금리를 바꾸면 공종별 공사비·공사기간·준공일·자금 흐름·3D 시공 시점이 즉시 다시 계산됩니다.

**v3.9.2 카메라·승강기**: 기본은 스크롤에 따른 이동입니다. Lintel의 두 단계 응답을 참고하고 사용자 요청에 맞춰 입력 반응을 높였습니다. 실제 표시되는 회전은 초당 16도, 실내 보행은 1.05m/s 이내로 제한합니다. 업무동은 기둥 사이 문 중앙으로 직진하고 문을 충분히 지난 뒤 로비에서 회전합니다. 실내 최고 보행 속도는 유형별 약 0.8~1.0m/s이며, 방별 대기를 삭제해 자동 재생과 스크롤 모두 안내 지점을 연속으로 통과합니다. 스크롤 감속은 0.45초, 카메라 응답 계수는 16이며 반대 방향 입력은 이전 감쇠를 바로 취소합니다. 장면 버튼은 종이색 전환으로 목적지에 연결하고, 슬라이더·스크롤바는 위치를 직접 선택합니다. 스크롤 트랙의 60%를 실내에 배분하며 입력이 없으면 감속해 정지합니다. 승강기가 있는 4개 유형은 1층·2층·중간층·최상층을 방문합니다. 층별 문·객실·레일·샤프트·관찰창이 실제 위치를 따라 움직이며, 전원주택은 실내 계단을 유지합니다. `층별 투어`·`승강기 타기`는 선택 재생입니다. 구현과 검증은 `docs/CAMERA_MOTION.md`에 있습니다.

**사이트 헤더**: 브랜드·홈·소개·GitHub·WAN2 링크를 종이색 고정 헤더에 표시합니다. 건물 유형과 장면 이동은 아래 조작 영역에서 선택하며, 좁은 화면에서는 유형 버튼을 가로로 스크롤합니다.

**탐색**: 상단 진행률 막대로 11개 장면을 직접 탐색하고, 공정표 위 주차 슬라이더로 시공·기성·자금을 같은 시점에서 확인합니다. 실내에서는 `공간만 보기`로 설명·정지점 탭·미니 평면을 접고, 이전/다음 방 이름을 보며 이동할 수 있습니다. 방 카드에는 같은 평면 데이터의 면적·치수·바닥·층고가 표시됩니다. Space는 재생/정지, 실내 ←/→는 방 이동, H는 설명 접기입니다. 입력란을 편집할 때는 단축키가 개입하지 않습니다. 자세한 비교·반영 기록은 `docs/REFERENCE_UPDATE.md`에 있습니다.

**법규 → 자동 매스** (우측 상단 `법규·공사비 산정`): 용도지역·대지 폭·깊이·전면도로 폭을 바꾸면 건폐율·용적률·정북 일조 이격·대지 안의 공지·유형 요건(다세대 4개층·660㎡, 임대형기숙사 20실·공동취사 50%)을 모두 만족하는 **층수와 평면 크기**를 찾아 3D·공사비·공기·자금에 바로 반영합니다. 항목마다 적합/부적합/권고 미충족/확인 필요와 근거 조문을 표시하고, 3D에는 대지 경계·일조사선·층별 건축가능영역을 주황색으로 그립니다. 법규 값은 `js/law.js` 한 곳에 있으며 법령 MCP로 검증합니다 (`docs/LAW_MCP_SETUP.md`).

**실사 품질**: 물리 하늘, 하늘 반사, AO, 범프 재질을 씁니다. 상단 `고품질` 버튼이나 `?q=low`로 끕니다. **카메라**는 유형마다 공정 시점에 맞춘 동선(터파기 → 골조 → 외장 → 준공)을 따릅니다.

**주차 대수 산정** (`js/parking.js`)
- 법정 필요 대수
  - 근생·업무·기숙사: 주차장법 시행령 별표1 (서울은 조례값)
  - 다세대: 주택건설기준 제27조 (세대당 대수와 전용면적 기준 중 큰 값)
  - 용도별 대수를 합산한 뒤 별표1 비고의 끝수 규칙을 적용
- 배치
  - 필로티: 기둥 사이 2.5×5.0m 구획(소규모 특례 포함)
  - 지하: 기계식으로 보고 층당 대수와 필요 지하 층수를 계산
  - 전원주택: 앞마당 옥외 주차
- 필로티형은 주차가 **매스 조건**이라 세대·실 수가 주차로 정해집니다.
- 지하형은 기계식 설비비와 추가 지하층 공사비가 공사비에 들어갑니다.
- 장애인 전용(10대 이상 2~4%), 확장형(50대 이상 30%), 서울 주차상한제(설치제한 지역 선택 시)도 반영합니다.

## 실행

모듈을 쓰므로 `index.html` 더블클릭으로는 동작하지 않습니다 (그렇게 열면 화면에 안내가 뜹니다).

- **VS Code + Live Server**: 폴더 열기 → `index.html` 우클릭 → *Open with Live Server*
- **Python이 있으면** `run.bat` 더블클릭
- 인터넷 필요 (three.js·폰트 CDN). 노트북·데스크톱 브라우저 권장.

새 체크아웃의 검증은 `npm install --ignore-scripts` → `npm test`로 실행합니다. `npm run build`는 웹 실행 파일만 `dist/`에 모읍니다. Firebase Hosting은 독립 프로젝트 `formequa-process-study`의 `study` 대상으로 배포합니다. 자세한 명령은 `docs/DEPLOYMENT.md`에 있습니다.

문제가 생기면 화면 가운데 **빨간 오류 상자**가 뜹니다. 그 내용을 캡처해 주시면 원인을 바로 찾을 수 있습니다.
